Relation

A rule that links things together.

Example‘The more you exercise, the fitter you get’ links exercise and fitness.

Function

A relation where each input gives exactly one output.

Example‘Double the input’ is a function: 3 always gives 6.

Input

The number you put into a function.

ExampleIn f(4) = 9, the input is 4.

Output

The number that comes out of a function.

ExampleIn f(4) = 9, the output is 9.

Rule

What the function does to each input.

ExampleRule: ‘add 5’. Input 2 gives output 7.

Mapping diagram

A diagram with arrows from each input to its output.

Example1 → 3, 2 → 5, 3 → 7 for the rule 2x + 1.

Couples

Input and output written together in brackets.

Example(2, 5) means input 2 gives output 5.

Ordered pairs

Another name for couples. The order matters: (input, output).

Example(3, 7) is not the same as (7, 3).

Domain

The set of all inputs.

ExampleFor {(1, 4), (2, 5)}, the domain is {1, 2}.

Range

The set of outputs the function actually gives.

ExampleFor {(1, 4), (2, 5)}, the range is {4, 5}.

Codomain

The set of all possible outputs. The range is always inside the codomain.

ExampleCodomain {1, 2, 3, 4, 5, 6}, range {4, 5}.
