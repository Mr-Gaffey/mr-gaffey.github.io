Function

A rule that gives exactly one output for every input.

Examplef(x) = 2x + 3
f(4) = 2(4) + 3 = 11

Input

The value you put into a function (usually x).

ExampleFor f(x) = x², putting in 5 means the input is 5.

Output

The value the function gives back.

Examplef(5) = 25, so the output is 25.

Domain

The set of all the inputs of a function.

ExampleIf f(x) = 2x uses inputs {1, 2, 3}, the domain is {1, 2, 3}.

Range

The set of outputs the function actually produces. (Careful: in statistics, range means something different.)

Examplef(x) = 2x with domain {1, 2, 3} gives range {2, 4, 6}.

Codomain

The set of all outputs that are allowed. The range is the part of the codomain that is actually used.

Examplef: ℕ → ℕ, f(x) = 2x. Codomain = ℕ, but the range is only the even numbers.

Composite function

One function applied to the output of another. f(g(x)) means do g first, then f.

Examplef(x) = x + 1, g(x) = 3x
f(g(x)) = 3x + 1, so f(g(2)) = 7

Linear function

A function of the form f(x) = ax + b. Its graph is a straight line.

Examplef(x) = 2x − 1 has slope 2 and cuts the y-axis at −1.

Quadratic function

A function of the form f(x) = ax² + bx + c, where a ≠ 0. Its graph is a U-shape (a > 0) or an upside-down U (a < 0).

Examplef(x) = x² − 4 is U-shaped and crosses the x-axis at −2 and 2.
