Categorical data

Data that describes a quality or category, not a number.

ExampleFavourite band, eye colour.

Numerical data

Data that is a number, counted or measured.

ExampleNumber of houses built, heights.

Population

The entire group being studied.

ExampleAll teenagers in Ireland.

Sample

A group selected from the population.

Example400 randomly selected teenagers.

Representative / unbiased

A sample that is typical of the population.

ExampleTeenagers of all ages, from all over Ireland.

Biased

A sample that is not typical of the population.

ExampleOnly 19-year-olds asked about all teenagers.

Bar chart

Bars of equal width whose heights show frequencies, with gaps between them.

ExampleFavourite subjects with the number of students.

Pie chart

A circle split into sectors, each showing a fraction of the total.

Example9 hours sleeping out of 24 = 9/24 × 360° = 135°.

Line plot

A number line with an X for each piece of data.

ExampleDays absent, with one X per day.

Stem-and-leaf plot

A table splitting each number into a stem (tens) and leaf (units).

ExampleKey: 2 | 7 = 27.

Back-to-back stem-and-leaf plot

Two stem-and-leaf plots sharing one stem, to compare two data sets.

ExampleTest 1 and Test 2 scores on either side.

Trend graph

A line graph showing how data changes over time.

ExampleMonthly complaints over a year.

Mode

The most common value.

Example{2, 3, 3, 7}: mode = 3.

Median

The middle value when the data is in order.

Example{1, 2, 3, 4}: median = 2.5.

Mean

Add all the values and divide by how many there are.

Example{3, 5, 7, 9}: mean = 24 ÷ 4 = 6.

Range

Maximum value minus minimum value. It measures spread.

Example{8, 9, 14}: range = 14 − 8 = 6.

Maximum value

The largest value in the data set.

ExampleIn {4, 11, 7}, the maximum is 11.

Minimum value

The smallest value in the data set.

ExampleIn {4, 11, 7}, the minimum is 4.

Grouped frequency distribution

A table showing how many values fall in each interval.

ExampleAge 0–20: 24 people, 20–30: 16 people.

Histogram

Like a bar chart but for grouped measured data, with no gaps between the bars.

ExampleDistances to school in 2 km groups.

Outlier

A value much bigger or smaller than the rest.

Example18.27 s among times of about 13.5 s.
