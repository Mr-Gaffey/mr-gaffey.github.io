Probability scale

A number line from 0 (impossible) to 1 (certain).

Example0.5 is an even chance. 0.9 is very likely.

Likelihood scale

A line showing how likely something is, in words, from impossible to certain.

ExampleImpossible, unlikely, even chance, likely, certain

Trial

Doing an experiment once.

ExampleRolling a die one time.

Outcome

One of the possible results of a trial.

ExampleGetting a 4 when you roll a die.

Sample space

The set (list) of all possible outcomes.

ExampleRolling a die: {1, 2, 3, 4, 5, 6}

Event

One or more outcomes of an experiment.

ExampleRolling an even number: {2, 4, 6}

Relative frequency

The number of times an event happened ÷ the number of trials.

Example18 heads in 50 tosses: 18 ÷ 50 = 0.36

Expected frequency

How many times you expect an event to happen.
Probability × number of trials

ExampleRoll a die 300 times: expect ⅙ × 300 = 50 sixes

Fairness

A coin, die or spinner is fair if every outcome is equally likely. A game is fair if, on average, nobody gains or loses: the expected value equals the cost to play.

ExampleA game costs €2 and the expected winnings are €2, so the game is fair.

Equally likely

Outcomes that all have the same probability.

ExampleEach face of a fair die is equally likely, with probability 1⁄6.

Theoretical probability

A probability worked out by reasoning, without doing the experiment.

ExampleP(king from a deck) = 452 = 113

Set theory

Using sets and Venn diagrams to show events. ∪ means OR, ∩ means AND.

ExampleP(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Mutually exclusive events

Events that cannot happen at the same time. P(A or B) = P(A) + P(B)

ExampleRolling a 2 and rolling a 5 on one roll.

AND/OR events

P(A or B) = P(A) + P(B) − P(A and B). Take away the overlap so it isn’t counted twice. For independent events, P(A and B) = P(A) × P(B).

ExampleOne card: P(red or king) = 26⁄52 + 4⁄52 − 2⁄52 = 28⁄52 = 7⁄13

Two-way table

A grid that shows all the outcomes of two events together.

ExampleTwo dice in a 6 × 6 grid give 36 outcomes.

Tree diagram

A diagram with branches showing the outcomes of one event followed by another.

ExampleA coin tossed twice has 4 branch endings.

Independent events

The result of one event does not affect the other. P(A and B) = P(A) × P(B)

ExampleHead on a coin and 6 on a die:
½ × 16 = 112

Bernoulli trial

A trial with only two outcomes, success or failure, where the chance of success is the same every time.

ExampleRolling a die where success = 6, p = 16.
First 6 on the 3rd roll: 56 × 56 × 16 = 25216

Expected value

The average result you'd expect in the long run. Multiply each value by its probability and add.

ExampleWin €10 with probability 0.2, else €0:
E = 10 × 0.2 = €2. If it costs €3 to play, it is not a fair game.
